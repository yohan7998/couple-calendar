## ✨ 핵심 기능 소개

### 1. 🎫 음주 티켓 설정 및 차감 라이프사이클
- **목표 티켓 설정**: 이번 달 음주 목표 횟수(예: 8회)를 설정합니다.
- **실시간 차감**: 술을 마실 때마다 티켓이 1장씩 차감되며 잔여 티켓과 절주 상태가 표시됩니다.
- **음주자 기록**: `🥂 둘이 함께`, `🐻 주니`, `🐰 용이` 중 누가 마셨는지만 깔끔하게 기록 (주종 구분 없이 간소화).

### 2. 📅 달력 일자별 음주 횟수 표기
- 달력 월간 그리드 내 음주 날짜 아이콘(🍺 / 🥂) 바로 아래 **`1회`**, **`2회`**, **`3회`** 형태의 핑크 캡슐 뱃지가 렌더링되어 한눈에 당일 음주 횟수를 확인할 수 있습니다.

### 3. 💌 주니 ➔ 용이, 용이 ➔ 주니 2분할 전용 쪽지함
- **독립된 2개 수신 탭**:
  - `[🐻 주니 ➔ 용이에게 (N)]`: 주니가 용이에게 전한 사랑의 쪽지 및 심부름 메모
  - `[🐰 용이 ➔ 주니에게 (N)]`: 용이가 주니에게 전한 응원 및 당부의 쪽지
- 쪽지별 하트(💖) 리액션 및 **"특별 음주 허가권(+1장 선물 🎫)"** 기능 지원.
- 쪽지 작성 시 현재 탭에 맞춰 발신자가 자동 설정됩니다.

### 4. 🔔 새 쪽지 도착 실시간 알림 & 멜로디 차임벨 알람
- **브라우저 웹 푸시 (Web Notification API)**: 다른 탭을 보거나 백그라운드 상태에서도 OS 레벨 시스템 알림 배너 발송.
- **청아한 챠임벨 (Web Audio API)**: 새 쪽지 수신 시 자체 합성되는 맑은 4음계 챠임벨(도-미-솔-도) 연주 (`[🔊 소리 테스트]` 지원).
- **인앱 상단 토스트 배너**: 앱 사용 중 상단 슬라이드 다운 팝업을 터치하면 해당 쪽지함으로 즉시 이동.
- **30초 자동 폴링**: 백그라운드 30초 주기 동기화 및 탭 활성화 감지(`visibilitychange`).

### 5. 🔒 GitHub Gist 무인프라 실시간 2인 동기화
- 개인 토큰(PAT)과 Secret Gist ID를 등록하면 부부 스마트폰 간에 실시간으로 데이터가 동기화됩니다.
- **카카오톡 초대 링크**: 설정 모달에서 '카카오톡 초대 링크 복사'를 누르고 배우자에게 전달하면, 배우자는 링크 터치 한 번으로 복잡한 토큰 입력 없이 즉시 자동 동기화됩니다.

## 📱 스마트폰 홈 화면 추가 (앱처럼 사용하기)

1. **아이폰 (Safari)**:
   - Safari에서 [https://yohan7998.github.io/couple-calendar/](https://yohan7998.github.io/couple-calendar/) 접속
   - 하단 중앙의 **공유 버튼(네모+화살표)** 터치
   - **'홈 화면에 추가'** 선택 ➔ 완료
2. **갤럭시 / 안드로이드 (Chrome)**:
   - Chrome에서 접속
   - 우측 상단 **더보기(점 3개)** 터치 ➔ **'홈 화면에 추가'** 또는 **'앱 설치'** 선택
